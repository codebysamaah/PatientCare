# Patient Management System

## Description

A full-stack healthcare web application with **separate portals** for doctors and patients.  
Doctors can manage appointments, patient medical history, and prescriptions, while patients can view their own information and schedule visits. 

This project demonstrates full-stack development skills, including CRUD operations, user authentication, database integration, and responsive front-end design.

## Features

### Doctor Portal
- Register a new patient
- View, edit, and delete patient information
- Schedule, track, and manage appointments
- Upload and manage patient prescriptions
- Role-based authentication to secure access
- Dashboard to view upcoming appointments and recent patient activity

### Patient Portal
- View personal medical history and prescriptions
- Schedule and track appointments
- Secure login to access private data
- Simple and intuitive interface for easy navigation

### General
- CRUD operations for all relevant data
- Responsive design for desktop and mobile use
- Error handling and form validation for smooth user experience

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB
